# 贴内衬机视觉定位系统

## 项目简介

工业级、科技风、HUD风格的贴内衬机视觉定位系统，支持摄像头实时采集、相机标定、双直线/双外形模板匹配、贴料参数设置等核心功能。

## 核心功能模块

### 1. 摄像头控制模块
- USB摄像头检测与选择
- 分辨率设置（640x480 / 800x600 / 1280x720 / 1920x1080）
- 实时画面显示
- 摄像头状态监控

### 2. 相机标定模块
- 九点标定方法
- 像素-物理坐标转换
- 标定结果自动保存
- 标定状态实时显示

### 3. 双直线模板设置（矩形专用）
- 左/右监测区域圈定
- 左/右模板直线绘制
- 面纸A基准保存
- 手动测试识别
- 模板保存与加载

### 4. 双外形模板设置（异形专用）
- 左/右特征区框选
- Canny边缘检测参数调节
- 轮廓匹配阈值设置
- 模板匹配测试
- 异形模板保存

### 5. 贴料参数设置
- X/Y/Z/A偏移补偿
- 匹配分数阈值
- 超差报警限值
- 识别超时时间
- 拍照延时设置
- 真空延时设置
- 失败处理模式（报警停止/自动重试/跳过继续）
- 参数保存与加载

## 使用流程

### 直线模板模式（矩形面纸）

1. 点击「检测摄像头」选择可用设备
2. 点击「打开摄像头」启动采集
3. 放置标准矩形面纸
4. 点击「左监测区域」圈定左侧识别范围
5. 点击「右监测区域」圈定右侧识别范围
6. 点击「画左模板」在画面上画出左侧直线
7. 点击「画右模板」在画面上画出右侧直线
8. 点击「面纸A基准」保存模板
9. 点击「手动测试」自动拍照识别
10. 识别后显示：监测区域框、识别直线、实时数据

### 外形模板模式（异形面纸）

1. 切换模式为「双外形模式(异形)」
2. 调整Canny阈值和匹配阈值
3. 点击「框选左特征区」圈定左侧特征
4. 点击「框选右特征区」圈定右侧特征
5. 点击「测试识别」验证匹配效果
6. 点击「保存异形模板」保存配置

### 相机标定

1. 选择标定方法（九点标定推荐）
2. 添加标定点（至少2个）
3. 输入像素坐标和对应的物理坐标(mm)
4. 点击「计算标定」完成标定
5. 标定结果用于后续坐标转换

### 贴料参数设置

1. 设置X/Y/Z/A偏移补偿值
2. 配置匹配分数阈值
3. 设置X/Y/A报警限值
4. 调整时序参数（超时、延时）
5. 设置失败处理模式和重试次数
6. 保存参数供后续使用

## 算法特性

- **Canny边缘检测**
- **Hough直线变换**
- **轮廓匹配（Hu矩）**
- **坐标转换标定**
- **滤波去噪**
- **亚像素精度**
