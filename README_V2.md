## 📐 相机标定原理详解

### 一、针孔相机模型

相机成像遵循针孔模型，3D空间点通过投影变换映射到2D图像平面。

### 二、内参矩阵 (Intrinsic Matrix)

```
K = | fx  0  cx |
    |  0 fy  cy |
    |  0  0   1 |
```

**参数说明**：
- `fx, fy`：焦距（像素单位）
- `cx, cy`：主点坐标（图像中心）

### 三、畸变模型

**径向畸变**：k1, k2, k3, k4, k5, k6
**切向畸变**：p1, p2

**畸变校正公式**：
```
x_distorted = x(1 + k1*r² + k2*r⁴ + k3*r⁶) / (1 + k4*r² + k5*r⁴ + k6*r⁶) + 2*p1*x*y + p2*(r² + 2*x²)
y_distorted = y(1 + k1*r² + k2*r⁴ + k3*r⁶) / (1 + k4*r² + k5*r⁴ + k6*r⁶) + p1*(r² + 2*y²) + 2*p2*x*y
```

### 四、外参矩阵 (Extrinsic Matrix)

```
[R|t] = | r11 r12 r13 tx |
        | r21 r22 r23 ty |
        | r31 r32 r33 tz |
```

**参数说明**：
- `R`：旋转矩阵（3x3）
- `t`：平移向量（3x1）

### 五、投影方程

```
s * [u, v, 1]ᵀ = K * [R|t] * [X, Y, Z, 1]ᵀ
```

## 🔧 标定流程详解

### 方法一：棋盘格标定（推荐）

**步骤**：
1. **准备标定板**
   - 使用棋盘格标定板（推荐9x6或10x7内角点）
   - 打印精度要求高，确保平整
   - 方格尺寸已知（如25mm）

2. **采集图像**
   - 从不同角度、距离拍摄至少15-20张图像
   - 覆盖整个视场，包括边缘区域
   - 确保图像清晰，无模糊
   - 每张图像中棋盘格应占画面30%-70%

3. **检测角点**
   - 使用`findChessboardCorners`检测角点
   - 使用`cornerSubPix`亚像素精度优化
   - 角点检测失败会提示调整角度

4. **求解参数**
   - 使用`calibrateCamera`求解内参和畸变系数
   - 使用`solvePnP`求解外参

5. **评估精度**
   - 计算重投影误差（RMS）
   - 误差 < 0.5像素：优秀
   - 误差 < 1.0像素：良好
   - 误差 > 1.0像素：需重新标定

6. **应用校正**
   - 使用`initUndistortRectifyMap`生成映射
   - 使用`remap`进行图像校正

### 方法二：点对应标定

**步骤**：
1. 准备已知物理尺寸的标准件
2. 测量特征点在图像中的像素坐标
3. 输入对应的物理坐标（mm）
4. 计算像素/毫米比例

**适用场景**：
- 快速标定
- 精度要求不高
- 无标定板

## 🚀 使用指南

### 启动程序

```bash
python vision_gui_v2.py
```

### 双直线模板设置流程

1. **打开摄像头**
   - 点击「检测摄像头」
   - 选择摄像头设备
   - 选择分辨率
   - 点击「打开摄像头」

2. **设置左侧模板**
   - 点击「画长边」→ 在画面上绘制左侧长边
   - 点击「画短边」→ 在画面上绘制左侧短边
   - 系统会自动验证两条边是否垂直

3. **设置右侧模板**
   - 点击「画长边」→ 在画面上绘制右侧长边
   - 点击「画短边」→ 在画面上绘制右侧短边

4. **设置监测区域**
   - 点击「设置左监测区域」→ 框选左侧识别范围
   - 点击「设置右监测区域」→ 框选右侧识别范围

5. **保存模板**
   - 所有设置完成后，「保存当前模板」按钮自动启用
   - 点击保存，系统会计算并显示基准数据

6. **手动测试**
   - 保存模板后，「手动测试」按钮自动启用
   - 点击测试，系统会在监测区域内检测直线
   - 显示检测结果和计算数据

### 异形模板设置流程

1. **打开摄像头**（同上）

2. **调整参数**
   - 设置Canny边缘检测阈值
   - 设置轮廓匹配阈值

3. **框选轮廓**
   - 点击「框选左轮廓」→ 框选左侧特征区域
   - 点击「框选右轮廓」→ 框选右侧特征区域
   - 系统会自动提取最大轮廓

4. **设置监测区域**
   - 点击「设置左监测区域」→ 框选左侧识别范围
   - 点击「设置右监测区域」→ 框选右侧识别范围

5. **保存模板**
   - 所有设置完成后，「保存当前模板」按钮自动启用
   - 点击保存

6. **手动测试**
   - 保存模板后，「手动测试」按钮自动启用
   - 点击测试，系统会在监测区域内匹配轮廓
   - 显示匹配结果和计算数据

### 相机标定流程

#### 棋盘格标定

1. **准备标定板**
   - 打印棋盘格标定板（推荐9x6内角点）
   - 确保打印平整、尺寸准确

2. **设置参数**
   - 输入棋盘格内角点数量（列x行）
   - 输入方格物理尺寸（mm）

3. **采集图像**
   - 从不同角度拍摄至少15张图像
   - 点击「采集标定图像」
   - 系统会自动检测棋盘格并计数

4. **执行标定**
   - 采集足够图像后，点击「执行标定」
   - 系统会计算相机参数和重投影误差

5. **查看结果**
   - 标定成功后显示：
     - 重投影误差
     - 焦距（fx, fy）
     - 像素/毫米比例

6. **保存标定**
   - 点击「保存标定」保存标定数据

#### 点对应标定

1. **切换方法**
   - 选择「点对应标定」

2. **添加标定点**
   - 点击「添加点」
   - 输入像素坐标和物理坐标
   - 至少添加2个点

3. **计算标定**
   - 点击「计算标定」
   - 系统会计算像素/毫米比例

## ⚙️ 算法说明

### 双直线检测算法

1. **边缘检测**
   ```python
   gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
   blurred = cv2.GaussianBlur(gray, (5, 5), 1.4)
   edges = cv2.Canny(blurred, 50, 150)
   ```

2. **直线检测**
   ```python
   lines = cv2.HoughLinesP(edges, 1, np.pi/180, 50, minLineLength=30, maxLineGap=10)
   ```

3. **交点计算**
   ```python
   intersection = calculate_line_intersection(line1, line2)
   ```

4. **角度计算**
   ```python
   angle = math.degrees(math.atan2(y2-y1, x2-x1))
   ```

### 异形轮廓匹配算法

1. **轮廓检测**
   ```python
   contours, _ = cv2.findContours(edges, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
   ```

2. **形状匹配**
   ```python
   score = cv2.matchShapes(template, contour, cv2.CONTOURS_MATCH_I1, 0)
   match_score = 1.0 / (1.0 + score)
   ```

3. **中心计算**
   ```python
   M = cv2.moments(contour)
   cx = M['m10'] / M['m00']
   cy = M['m01'] / M['m00']
   ```

## 🔍 故障排除

### 问题1：摄像头无法打开
**解决方案**：
- 检查摄像头是否被其他程序占用
- 尝试不同的摄像头索引
- 检查摄像头驱动是否正常

### 问题2：棋盘格检测失败
**解决方案**：
- 调整拍摄角度，避免过大倾斜
- 确保棋盘格完全在画面内
- 提高环境光照
- 检查棋盘格是否平整

### 问题3：直线检测不准确
**解决方案**：
- 调整Canny阈值
- 确保监测区域设置合理
- 提高图像对比度

### 问题4：轮廓匹配失败
**解决方案**：
- 降低匹配阈值
- 重新选择特征区域
- 调整Canny参数
